🗞️ Mission 1 — Newsroom Fix-Up (12)

1A · Fix errors (5) — 1 pt per correct fix, any 5 of:

1B · Sentence that doesn't belong (3): "The fastest land animal is the cheetah." — off-topic, breaks the article's focus. 3 = finds + explains; 2 = finds, thin why; 1 = senses something off; 0 = misses.

1C · Headline (2): accurate + catchy (e.g., "Nine Brains, Three Hearts: Meet the Ocean's Genius"). 2 = both; 1 = flat or slightly off; 0 = missing.

1D · Stronger words (2): 1 pt each precise swap. E.g., amazing→astonishing, strangest→most bizarre, tiny→miniature, experts→masters.

⭐ Mission 2 — Story Reviewer (13)

2A rating + hook — warm-up, not scored.

2B · Theme + turning point w/ evidence (7):
Theme (3): courage = acting despite fear; strength comes from connection/love, not perfection. (Accept supported variations.)
Turning point + 2 quotes (4): the moment she "looked up" and found Arun → chooses to play. 2 pts correct turning point + 1 pt per accurate quote (e.g., "she looked up," "the exit sign glowed red and kind," "voice cracked … like ice on a pond").

2C · Figurative language (2): example + its effect. E.g., "microphone waited like an open mouth" (simile, threatening); "her fingers turned to strangers" (metaphor, lost control). 2 = example+effect; 1 = example only.

2D · Recommendation (3): 3 = names who + convincing why tied to story; 2 = generic reason; 1 = "it's good"; 0 = none.

🔍 Mission 3 — The Case File (11)

3A · Solve it (4): The loose hamster (Nibbles) wrecked/ate the model — no human thief. Window locked + only other key-holder out of town rule out people; the open cage latch, quiet "guilty" hamster, empty water bottle, and the reddish "lava" ring + cracker crumb point to Nibbles. 4 = lands on hamster w/ reasoning; 3 = right, thin; 2 = rules out humans only; 1 = guess. Accept any solution that fits ALL clues — reward reasoning.

3B · Cite clues (3): 1 pt each — (a) locked window + key-holder away = no human entry; (b) open latch + quiet hamster + empty bottle = Nibbles loose; (c) reddish ring + crumb = model disturbed at the scene.

3C · Words in context (4): confirmed = proven true/backed up (clue: "by three relatives"). secured = fastened/locked shut (clue: contrast "hung open," "normally"). 2 each = meaning + how he knew; 1 = meaning only.
