# Matchday26 — 设计与美学宗旨 (DESIGN.md)

> 这是产品的设计"宪法"。Sheng 出方案、龙哥审美、实现 agent 落地，都以此为准绳。
> 老板（架构/规则）拥有最终修改权。

## 一句话宗旨
让一个准备奔赴 2026 世界杯的球迷，**打开应用第一秒就感到"这是我的赛事时刻"**，并在**三步之内自信完成预订**。

## 情绪锚点（奢华暗色版 · 2026-06-10 老板拍板）
**"深夜交易大厅般的沉稳与高级——深蓝近黑画布、克制的冷蓝行动色、点到为止的奢华金；数据清晰、价值醒目，我准备好下注我的世界杯之旅。"**
手法：**深色奢华**（参照 Polymarket 设计层）——navy-charcoal 画布 + 发丝级边框面板 + 冷蓝 `#3d8bff` 行动色 + 奢华金 `#c9a55c` 守价值/价格；近白文字、紧凑 grotesk、tabular 数字。
> 取代上一版"亮色 WC2026"。老板指示"luxury like + 类 Polymarket 设计层"——故由亮转暗、以高级感与数据密度为先（本轮落地）。亮色作为可逆备选仍保留在 token 双轨里（改 `@theme`/`:root` 即可回切）。

## 五条核心原则
1. **简单优先（≠单调）**：每屏一个主行动、路径简单；**允许"节日密度"**（大字倒计时/城市点/数据）——只要层级清晰，丰富是欢腾的证明，不是混乱。
2. **信任即转化**：真实数据、清晰价格、**绝不伪造稀缺/折扣**（无暗黑模式）。节日越高调，这条越是差异化资产。
3. **层级清晰**：一眼看到最重要的那个——标题 → 价格 → CTA。
4. **克制的动效（含节日例外）**：功能反馈仍 0.15–0.25s；**仅 3 个庆典触发点**放行 0.4–0.8s 的**一次性**叙事动效——①预订完成彩带 ②倒计时数字跳动 ③进球脉冲（卡片 hover 橙环）。`prefers-reduced-motion` 无条件遵守、立即关闭。
5. **无障碍是底线**：正文对比 ≥ WCAG AA 4.5:1；可键盘、可读屏。

## Do / Don't
- **Do**：深色奢华画布 + 发丝边框面板；冷蓝守行动（CTA/链接/焦点）、金守价值（价格/徽章）；数据密度高但层级清晰；卡片轻浮起；骨架屏；近白正文过 WCAG AA。
- **Don't**：≥3 个强调色同屏、金当大面积背景、白字叠金底、伪造"只剩 3 间"、循环不停的动画、低对比文字、把政治/法律文案混进界面。

## 转化优先（落地准则）
- 价格：大号**金字** + "From"；移动端价格不被截断。
- CTA：高对比填充 + 动作动词（如 `Find My Match →`）；移动端全宽、≥44px 高。
- 信任信号：只用**真实**数据（104 场 / 16 城 / 3 国）。
- 移动端单列、导航可横滑。

## 内容边界（与 Yifu / 运营一致）
界面与营销聚焦：**赛程、城市、省钱、紧迫感、物流体验**。
**不承载政治、签证/移民/法律责任类声明**；此类信息如确有必要，仅以链接指向官方来源，产品本身不提供法律建议。

## 落地路线（设计 roadmap，详见 CADENCE.md §6）
**节日化(Festival)优先**：① 节日色 token + Hero 球场双光晕 + 大字倒计时 → ② 卡片进球脉冲 hover → ③ 预订完成庆祝态（彩带 + 分享）→ 然后 8px 间距 / 价格对比徽章(A/B) / 外部素材（图·视频·Lottie，见 `design/moodboard-workflow.md`）。
> 纯 CSS 即可先上①②③，无需等外部素材；图片/视频/Lottie 为后续增强。每步先预览给老板。
