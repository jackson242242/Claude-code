# 记录表

只记这些，别的都别记。记录越简单越可能坚持。

## 每天一行（30 秒）

复制这一行到备忘录/表格，每天填：

```
日期 | 晨重(lb) | 步数 | 睡眠(h) | 训练(A/B/C/D/休) | 吃得如何(✅/⚠️/❌) | 备注
```

- **晨重**：起床、上完厕所、空腹、不穿衣、同一个秤
- **吃得如何**：✅ 基本按计划 ⚠️ 有偏差但可控 ❌ 失控。不写具体热量——写了你三周后就不写了
- **备注**：只在异常时写（应酬、生病、睡不好、关节不适）

## 每周日（5 分钟）

| 项目 | 记什么 |
| --- | --- |
| 7 日体重均值 | 把这周 7 个晨重加起来除以 7 |
| 与上周均值之差 | 对照 `PLAN.md` 的「每周自动校准」决定加减热量 |
| 训练完成 | 本周去了几次（目标 4，3 也合格，2 要复盘） |
| 步数达标天数 | 本周有几天达标 |
| 主项最好组 | 深蹲 / 卧推 / 硬拉，各记「重量 × 次数」 |

## 每 4 周（15 分钟，测量日）

| 项目 | 怎么量 |
| --- | --- |
| 腰围 | 肚脐水平、放松呼气末、**不收腹**、软尺贴皮不勒 |
| 胸围 | 乳头水平，手臂自然下垂 |
| 臂围 | 上臂最粗处，放松状态（不发力） |
| 大腿围 | 大腿最粗处 |
| 照片 | 正面 / 侧面 / 背面 · 同一位置 · 同一光线 · 同一条裤子 · 手机放同一高度 |
| 静息心率 | 晨起未下床时，数 60 秒 |

**照片必拍。** 第 8 周你照镜子会觉得「好像没变」，翻出第 1 周的照片就知道变了。这是最能防止你在第二个月放弃的一件事。
