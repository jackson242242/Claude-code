# 6 个月减脂塑形计划

230 lb → **203-206 lb**，26 周（2026-08-24 → 2027-02-21），每周健身房 3-4 次 / 每次 2 小时。
目标不是单纯变轻，是**降体脂 + 保肌肉 + 练出肩宽腰细的 V 型**，让衣服挂得住。

> 这份计划与本仓库的 World Cup 应用无关，是独立的个人计划目录，不参与前后端构建、测试或部署。

## 文件

| 文件 | 作用 |
| --- | --- |
| `PLAN.md` | **总纲**：目标拆解、6 个训练分块、营养分期、月度里程碑、每周自动校准。先读这个 |
| `NUTRITION.md` | 万能餐盘公式、**等量替换表**（换着吃不掉链子）、外食点单、备餐、购物清单 |
| `TRACKER.md` | 记录表模板：每天 30 秒、每周 5 分钟、每 4 周测量日 |
| `plan.py` | **每日卡片生成器** — 今天练什么、吃什么、代替品是什么 |
| `schedule/week-01..26.md` | 26 周逐周概览（由 `plan.py --render` 生成，可直接翻看） |

## 用法

```bash
python3 fitness/plan.py                    # 今天的完整卡片
python3 fitness/plan.py --tomorrow         # 明天的卡片（前一晚预告）
python3 fitness/plan.py --date 2026-09-15  # 任意一天
python3 fitness/plan.py --week 5           # 第 5 周概览
python3 fitness/plan.py --render           # 重新生成 schedule/ 下的 26 个周文件
python3 fitness/plan.py --selftest         # 校验 182 天全部可生成
```

每日卡片包含：所处分块和月度目标 → 今天的完整训练（动作、组数次数、要领、有氧、替代动作、加重规则）→ 今天的四餐（含热量/蛋白，**每餐都带代替品**）→ 当日步数/水/睡眠/称重 → 校准规则。

## 自动提醒（已配置）

两条 Routine，每天各触发一次，都会推送到手机：

| 时间（美东） | 内容 |
| --- | --- |
| **前一晚 21:00** | 明天的预告：练什么、吃什么、需要提前解冻/备的东西 |
| **当天早上 07:00** | 当天完整卡片：训练、四餐、代替品、今日 4 件小事 |

> **夏令时**：美东 11 月 1 日转 EST（UTC-5）。届时两条 Routine 的 UTC 时间需各 +1 小时，已另设一条一次性提醒在 2026-11-01 触发来处理。

## 计划的三条底层逻辑

1. **热量缺口决定掉多少斤** — 每天 -500 kcal ≈ 每周 -1 磅
2. **蛋白 180g + 力量训练决定掉的是脂肪还是肌肉** — 这一条决定你最后是「瘦」还是「tone」
3. **步数是最大的隐形变量** — 8000 → 12000 步 ≈ 每天多烧 150-250 kcal，且不抢恢复

## 免责

基于常规营养学与力量训练原则的通用方案，不是医疗建议。43 岁开始新的训练与减脂周期，**建议先做一次体检**（血压、血脂、血糖、肝肾功能）；有心血管、关节或代谢既往问题请先咨询医生。
