## 2. 三条主线

1. **画面换成第一人称。**
   - 素材优先级：你拍的 > 授权 POV > 地面视角。
   - 第 0 帧必须是前进的第一人称动作，或人眼高度的地面镜头；每条渲染后都查第 0 帧。
   - 航拍每条最多 1 个，永远不当第 0 帧。不用静图做假的走路运动。
2. **用干净的测量决定谁拿槽位。**
   - 每天三个格式同时跑，槽位按公式轮换，所以同一天的格式可以直接比：看 F2 对当天 F4 的 72h 播放比值，再看平均观看百分比（已按长度归一）。不再按"低触达日"剔除样本，所以不存在用被测视频自己判断触达的循环。
   - 测试期 F2、F4 都剪成 14-20 秒，避免短的格式在观看秒数上吃亏。
   - 订阅/千次有效播放只看全频道漏斗，不分格式：按现在的转化率，每个格式 3 周只会带来 1-2 个订阅，分不出高低。
   - 结果持平时保留 POV：你要的就是 POV，数据没说它更差就不砍。
3. **把看过的观众留下来。**
   - 隔周五发搜索型行程长视频，配 3 条同地点子 Short，并设 Related video 链接。
   - 频道页只写真话。
   - 建英文播放列表 "China POV Walks & Rides"（频道观众只看英文）。
   - 争取小博主授权合作。

- **做法**：
  - 测试期 14-20 秒（到 11-16），一个地点、一段乘坐或行走，第 0 帧是前进运动。
  - 字幕只用第二人称 "you"。地点名只按 placeSpeakable 说，也就是素材链接（slug）或 Commons 文件名里点了名的地方。
  - 字幕照该片段的核实记录写，不加画面里没有、也没有来源支撑的东西（时速、路线、台阶数）。

- **画面来源**：
  - `pov-library.json` 整库提交（保留所有标记），用的时候过滤：可用、非政治敏感、能认出是中国。例外是 3 条 Commons D 字头车次的车窗片（文件名里有车次号），只说 "D-train"，不说路线和地点。

## 6. 每天 loop 的改动

1. **读复盘**：
   - 格式只看同一天配对比值。
   - 钩子看同龄（48h/72h）结论，排除外部信号标出的低触达日；样本不到 6 条不下"有效"或"避免"的结论。
   - 连续 3 条 Short 在 48h 时都不到 15 播放，报告第一行写"去 Studio 检查"。
2. **选格式**：每天按公式把 [F2, F4, X] 分到 a/c/d 三个槽位。X 在周三、周日是 F3，周四是 F1，其余日子是 F4。
   - 不同意拍城市时，F2 每周最多 2 条，其余 F2 槽位给 F4。
   - 钩子类型仍按 HOOKS.md 的槽位指派；F3 所在槽位固定用 PRICE-SHOCK。
   - "POV:" 和 "Would you…" 句式只用于 F1/F2。
3. **素材**：
   - F2 和 F4 用 `--clips` 直接指定素材 id（上线前 F4 靠第 0 帧检查）。
   - 搜索词加 POV 词汇，不再加 aerial/drone。
   - 航拍每条 ≤1 个，且不在 0 秒；照片只做普通 Ken-Burns。
   - 没有诚实可用的素材，当天就发 2 条。
4. **文案**：
   - 库存素材上只用 "you"；"I / my / Follow me" 只用在你的素材上。
   - 地点名只能说在素材链接点了名的片段上；字幕照片段核实记录写，不加画面外的数字。
   - 价格要两个带日期的来源。
5. **声音**：按 3b。POV 片保留原声，先逐段检查店铺或街头音乐，有就静音那段；关掉 SFX 音效。
6. **元数据**：3 个 hashtag，tags 精简。`published.json` 每条加 `format`、`footage`、`povType`、`owner` 字段；RUNLOG 加 `fmt:<X>`。
7. **上传**：用了 AI 素材必须设 `containsSyntheticMedia=true`，否则上传器拒绝上传。
8. **报告**：
   - 每天：封面联系表（含每条的第 0 帧）+ 3 行摘要。
   - 每周五：社媒包（当周最好的 3 条干净母带）。

   - 取消每天 3 条母带投递和每条的 ADD SOUND 提示，只保留当周最佳 1 条。
9. **每周一**：10-26 起 POV 库补 ≥4 条（抽 3 帧人工确认）。每隔一周的周一做一次竞品扫描，读结果时跳过搬运频道。

## 10. 风险

- **POV 可能赢不了**：你的素材只有 6 条，没有播放优势；"带人画面"的证据也互相矛盾。测试结果可能是持平，持平时我们按你的偏好保留 POV。
- **你不同意拍城市**：F2 每周最多 2 条，判不出结果；6 条用完就暂停，等原始素材。
- **素材供给**：授权 POV 约 15-20 条后开始重复，大陆竖屏只有 1 条，补库命中率约 6%。没有原始素材，F1 剪 2-5 条就没了。
- **重剪像重复内容**：用旧镜头重剪，观众和推荐系统都可能当成重复。模糊带和换掉的音轨也削弱了 POV 感，所以要原始文件。
- **10-09..12 的塌陷还没解释**：10-13/14 已回升，但如果是频道级限制，所有格式都会表现差，要先解决它。
- **测量**：样本小，分布长尾；viewed-vs-swiped 只能在 Studio 看。Analytics API 不开，观看百分比只能靠 vidIQ（额度约 125、底线 40），判决只能看播放。
- **授权不等于原创**：热门 Pexels 片段可能在很多频道出现过。报道中的 10-01 原创性更新（未核实）可能压低所有库存素材。对策是你的素材优先、每条写独立脚本、带独立事实。
- **Content ID**：保留原声可能带进店铺或街头音乐，要逐段检查并静音。CC BY 曲偶有第三方误认领，要申诉。YouTube 音频库的曲子只能用在 YouTube，社媒母带要换掉。
- **ElevenLabs 条款**：如果条款不允许取消后继续商用付费期生成的音乐，那 10 条配乐就不能用，只剩 Commons 曲和你下载的音频库曲。
- **OAuth**：同意屏幕如果是 Testing 状态，refresh token 7 天失效，每日上传会断，所以重发 token 前必须先看。drive.readonly 能读你整个 Drive，不想给就走路径 B。
- **隐私与政治**：已知的儿童脸片段永不使用；遵守景区禁拍、禁飞规定。香港内容只做旅游，不碰政治；POV 库里 2 条天安门附近的片段已排除。季节指南只用官方已公布的事实，不给签证资格建议。
- **画质与版式**：横屏裁成 9:16 会掉清晰度，模糊底版式的留存可能更低，前 2 周测。
- **长视频**：可能怎么做都在 40 播放左右；无旁白字幕版的留存可能比有配音的低，11-20 检查时一起看。
- **你的时间**：一次性约 50 分钟，之后每周六约 10 分钟。周六的清单不做，Shorts 到长视频的链接就不存在。
- **代码风险**：新代码有 bug 会浪费真实槽位。所以只做 3 个小切片，每个都先过 `node --check`、每个格式试渲染 1 条、看联系表；过闸门之前一律用现有管线。
