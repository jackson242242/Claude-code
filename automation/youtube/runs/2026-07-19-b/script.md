# Slot B (2026-07-19) — 重庆不是一座城市，是一座立体迷宫

- **Pillar:** city-walk (Sunday longform, 16:9, ~102s) — odd-day Sunday = city-walk
- **Format:** longform, `heritage` grade, slow pace (seg 7-8), guzheng-calm bed, four movements
- **中式 checklist:** 成语/诗 line (曹操《短歌行》「山不厌高，水不厌深」) + 重庆话彩蛋「要得」+ hotpot craft close-up

## Four movements
1. **Establish** — a city with no flat ground, built between mountains and the Yangtze; even GPS gets lost.
2. **Walk + history** — Liziba: the monorail through an apartment block (built 2004, China's first straddle monorail, ~8s to pass through).
3. **Discovery twist** — Yangtze cable car ("first sky corridor over the river," locals' "sky bus"); climbing slopes as daily life; a red hotpot alley; the Chongqing word「要得」.
4. **Dusk reflection** — Hongyadong lights (Spirited Away's real-life town); the 曹操 line; "hard to walk turned into a view"; loop back to the 3D-maze opening with an on-screen invitation.

## Verified facts + sources (checked this run 2026-07-19)
- **李子坝轻轨穿楼**: Rail Transit Line 2 Liziba is China's first straddle-type monorail elevated station co-built with a residential/commercial building; built **March 2004**; Line 2 is China's first straddle monorail and the western region's first urban rail line. Train passes through the building in seconds ("8-second" popular framing). — 重庆本地宝 · 重庆市地方志办公室 · 重庆市政府网
- **长江索道**: billed as「万里长江第一条空中走廊」and「山城空中公共汽车」(sky bus); transformed from a river-crossing commute tool into a 网红 attraction. — 界面新闻 · 新浪
- **8D魔幻/网红城市**: cross-river cable cars, hillside escalators, monorail through buildings; a 立体 (three-dimensional) mountain city. — 界面新闻《一座"网红城市"的诞生》 · 中国日报网
- **洪崖洞** widely likened to the town in 宫崎骏《千与千寻》(Spirited Away). — 新浪旅游攻略
- **要得** (yào-dé) = "OK / it's a deal," a hallmark 西南官话 / Chongqing word (dialect-bank 四川/西南官话 set).
- Poem line: 「山不厌高，水不厌深」— 曹操《短歌行》.
