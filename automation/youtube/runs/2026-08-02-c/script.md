**Verified facts + sources (checked this run):**
- 口水鸡名字源自郭沫若《洪波曲》："少年时代在故乡四川吃的白砍鸡，白生生的肉块，红殷殷的油辣子海椒，现在想来还口水长流……"厨师取"口水"二字命名。川式冷盘/凉菜；1980s后期湖北人刘兴在重庆改良四川凉拌鸡。麻辣鲜香嫩爽；调料含姜葱蒜盐糖醋酱油红油麻油豆瓣花椒辣椒等二十余种；正宗多用四川花椒（麻）。— 维基《口水鸡》zh.wikipedia.org/wiki/口水鸡；百度百科《口水鸡》。
