**HONESTY NOTE (important):** sources disagree on whether a "travel eSIM" bypasses the Great
Firewall. The accurate distinction: a *local Chinese* SIM/eSIM sits behind the firewall (blocked
apps stay blocked); an *international roaming* eSIM keeps your phone's data on a foreign network,
so the traffic egresses outside China and blocked apps usually load. Hotel/venue WiFi is a local
Chinese network → still behind the firewall, so a pre-installed VPN is the honest backup. The
script and description state exactly this; no overpromising that "any eSIM unblocks everything."

## Verified facts + sources (found THIS run)
- China's Great Firewall blocks Google Search, Gmail, Google Maps, YouTube, WhatsApp, Instagram,
  Facebook, X, Telegram, Snapchat (10 major Western apps) for anyone on a local Chinese network.
- A travel/local eSIM gives data but does not by itself bypass the firewall; an international
  roaming eSIM that keeps you on a foreign network routes data abroad, so blocked apps typically
  work on the phone. Hotel Wi-Fi remains behind the firewall → keep a VPN installed as backup.
