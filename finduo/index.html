🌍 How global sharing works

Right now FinDuo is 100% offline — everything (your XP, streak, league) is saved in this browser, and the other learners on the leaderboard are friendly simulated players. That means it works instantly with no signup and no internet.

To share progress with real people around the world, FinDuo would add a small backend server:

  1. You sign in (or stay anonymous with a nickname).
  2. When you finish a lesson, your weekly XP is sent to the server.
  3. The server returns the real global/friends leaderboard.
  4. Your shareable card links to a public profile page.

The repo this ships in already uses FastAPI + PostgreSQL, so the same pattern (an endpoint like POST /xp and GET /leaderboard) drops right in. I kept the front-end's data calls in one place (Store) so swapping localStorage for a real API is a small change.
