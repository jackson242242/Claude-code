# 课程设计方法论 — 怎么设计一门"又深又有结构"的课

> Thomas 课的问题:**偏浅(大多停在"听懂比喻")+ 无结构(13 个并列小游戏,不是知识树)。**
> 这份文档定义我们怎么设计一门**严肃、深、有结构**的课。所有课(理财/AI/艺术…)都按这套来。
> 配套:`FRAMEWORK.md`(产品脊梁)· `curriculum/`(各领域的具体大纲)。

---

## 1. "结构"= 概念依赖图(DAG),不是话题清单

一门有结构的课,核心是一张**概念依赖图**:谁是谁的前置。

- 不能在教"现值(PV)"之前教 DCF;不能在教"杠杆 + 现金流"之前教 LBO。
- 课程的顺序 = **拓扑排序这张图**,而不是拍脑袋排话题。
- 找出**承重概念(load-bearing)**:少数几个一旦掌握,下游全盘解锁的概念。
  - 理财领域的承重概念就是 **货币时间价值(TVM)**——复利、债券定价、DCF、私募 IRR 全是它的衍生。
- **这正是 Thomas 课缺的**:它没有"前置→后继"的骨架,所以学完是一堆碎片,拼不成体系。

## 2. "深度"= 沿 Bloom 阶梯往上爬,不是堆更多事实

把每个概念按 **Bloom 认知层级**定位,深度 = 往上走,而不是横向加料:

| Bloom 层 | 学习者能做 | 我们的等级 | 理财例子 |
|----------|-----------|-----------|---------|
| Remember 记忆 | 复述定义 | L0 | "复利是钱生钱" |
| Understand 理解 | 用自己的话解释 | L1 | 解释为什么雪球后期更快 |
| Apply 应用 | 套公式算 | L2 | 用 FV=PV(1+r)ⁿ 算 30 年后多少钱 |
| Analyze 分析 | 拆解、比较、判断 | L3 | 两家公司,谁创造了价值?(ROIC vs WACC) |
| Evaluate 评估 | 在不确定下决策 | L3–L4 | 这个 LBO 值不值得做? |
| Create 创造 | 自己建模型/方案 | L4 | 自己搭一个 DCF / 设计一个投资组合 |

> Thomas 课几乎全部压在 Remember/Understand。**深 = 把同一个概念带到 Apply/Analyze/Create。**

## 3. 螺旋式课程(Bruner):核心概念反复回来,每次更深

不是"讲一次就过"。承重概念要在不同等级**反复出现、层层加深**:

- TVM 在 L1 是"雪球"(直觉)→ L2 是"算未来值"(公式)→ L3 是"DCF 给公司估值"→ L4 是"私募里的 IRR"。
- 同一根线,越缠越粗。这样知识有"复利",而不是学完就忘。

## 4. 阈值概念(Threshold Concepts)优先

每个领域有几个"传送门"概念——一旦想通,看世界的方式就变了。课程围绕它们组织:

- 理财的阈值概念:**① 货币有时间价值 ② 风险与回报不可分(没有无风险的超额回报) ③ 杠杆双刃 ④ 无套利 ⑤ 价值创造 = 回报 > 资本成本。**
- 把课程的"高潮"设在攻克这些阈值上,而不是平铺。

## 5. 先打靶错误心智模型(Misconception-first)

主动点名并击碎常见错误认知,比直接讲正确答案更有效:

- "股票=赌博""高回报不用高风险""杠杆=免费的钱""过去涨=未来涨"……
- 每个单元显式列出"你可能以为…,其实…"。

## 6. 具象→表征→抽象(CRA):必须落到抽象

- 具象(类比/故事)→ 表征(图/滑块模拟)→ **抽象(公式/模型)**。
- Thomas 课只走到具象就停了。**深度要求最终落到可计算的抽象层**——会算、会建模。

## 7. 掌握式 + 真实任务评估

- **掌握式进阶(Mastery)**:过了才解锁(`FRAMEWORK.md` 的门禁),配间隔重复 + 交错练习。
- **真实评估**:不是选择题,是"你能不能做"——搭一个组合、给一家公司估值、做一个 LBO 模型。

## 8. 建造优先(Constructionism)—— 最高教学法,且明确反"学校那一套"

> Papert 建构主义:**人在亲手造出一个对自己有意义的东西时学得最深。** 我们把它放在所有方法之上。

- **每一级都以"造出一个真东西"收尾**,而不是做完一张卷子。作品即门禁,作品即证据。
- **先造,再懂(build-first):** 先让人动手做出能跑/能玩的东西,过程中产生疑问,再回头补理论——
  而不是学校式的"先灌满理论,然后(往往永远不)应用"。
- **明确拒绝学校那一套:** 不被动听讲、不考试驱动、不为考而学、不只在纸上。
- **作品要"真"且"是自己的":** 真实数据、真实工具、可展示分享(也强化 `ENGAGEMENT.md` 的投入感)。

## 9. 跨度:小学 → 研究生(一条长螺旋,不是两个产品)

- 同一领域,**底端 7 岁可入门,顶端到研究生/专业级**(对标 `FRAMEWORK.md` §3 的 L0→L4 = 小学→研究生)。
- 不做"儿童版/成人版"两套;做**一根螺旋**,核心概念在每个学段以更深的形态 + 更硬的作品反复出现。
- 同一个承重概念,小学是"玩具版作品",研究生是"专业版作品"——例:TVM 从"三个罐子"一路到"亲手建 DCF/LBO 模型"。

## 一门课的标准结构(产出物)

每个领域的 `curriculum/<domain>.md` 都按这个结构写:

1. **承重概念 + 阈值概念**(这门课的脊柱)
2. **概念依赖图(DAG)**(谁前置谁)
3. **模块 → 单元**,每个单元标注:核心知识(真内容)· 阈值/承重?· 常见误解 · Bloom/L 等级
4. **螺旋线**:哪些概念在哪些等级反复加深
5. **Ultra-hard 顶峰**:这门课最难的几个高地在哪
6. **真实评估任务**:每个等级"毕业"要做出什么
