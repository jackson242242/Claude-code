## 0. 这门课的脊柱

**承重概念(掌握它们,下游全解锁):**
1. **货币时间价值(TVM)** —— 复利、债券、DCF、IRR 全是它的衍生。**整门课的原子。**
2. **风险与回报** —— 资产定价、组合、资本成本的底座。
3. **现金流** —— 报表、估值、杠杆收购都建在"现金怎么流"上。

**阈值概念(想通就换了双眼睛):**
- ① 一块钱今天 > 一块钱明天 ② 没有无风险的超额回报 ③ 杠杆双刃
- ④ 无套利(价格里已含信息)⑤ 价值创造 = 回报率 > 资本成本

**概念依赖图(主干):**
```
TVM ─┬─► 复利/储蓄        风险&回报 ─┬─► 组合理论(MPT)
     ├─► 债券定价                    ├─► CAPM ─► 股权成本 ─┐
     └─► DCF ◄── 自由现金流 ◄─ 三张报表                    ├─► WACC ─► DCF
                                     杠杆 ─► 资本结构 ─► LBO ◄┘
```

## M0 — 货币与时间(L0–L1)

| 单元 | 核心知识(真内容) | 标记 |
|------|------------------|------|
| **0.1 货币是什么** | 三职能:交换媒介 / 计价单位 / 价值储藏;法币 vs 商品货币;为什么通胀侵蚀"价值储藏";名义 vs 实际。 | 误解:"钱本身有价值"(其实是共识) |
| **0.2 货币时间价值(TVM)** | 一块钱今天 > 明天,因为能投资生息 + 通胀 + 不确定。现值/终值:**FV = PV·(1+r)ⁿ**;贴现率 r 是"等待与风险的价格"。 | ⭐**承重 + 阈值**。全课原子 |
| **0.3 复利与增长** | 几何 vs 算术增长;72 法则(72/r ≈ 翻倍年数);**实际回报 = (1+名义)/(1+通胀)−1**;费用也在复利——1% 管理费 30 年吃掉约 1/4 终值。 | 误解:"小费率无所谓" |
| **0.4 通胀与购买力** | CPI;名义≠实际;为什么"现金长期是亏的"。 | |

**L1 毕业任务:** 用 TVM 算"现在投 X,r% 复利 n 年后是多少 + 扣通胀后真实是多少"。

## M3 — 组合理论与市场(L2–L3)

| 单元 | 核心知识 | 标记 |
|------|---------|------|
| **3.1 量化风险** | 波动率 σ、分布、最大回撤;**波动 ≠ 永久亏损**(只有被迫卖出才变永久)。 | 误解 |
| **3.2 分散与 MPT(马科维茨)** | 相关性;系统性 vs 个体风险;有效前沿;**分散是"唯一的免费午餐"**(降风险不降预期回报)。 | ⭐**阈值** |
| **3.3 CAPM 与 β** | 预期回报 = rf + β·(市场溢价);只有系统性风险被定价;股权成本由此来;以及 CAPM 的局限。 | 承重(通向 WACC) |
| **3.4 市场有效性(EMH)** | 弱/半强/强式;主动 vs 被动;**扣费后多数主动跑输**→指数基金/ETF 的逻辑。 | 阈值:无套利 |
| **3.5 行为金融** | 损失厌恶、近因、羊群、过度自信;泡沫与反身性;市场为何并非完全有效。 | |

## M7 — 宏观语境(贯穿,L4 收口)

- 利率与央行、通胀、信贷周期。
- **一切通过贴现率相连**:利率↑ → 贴现率↑ → 所有资产价格↓(回扣 M0 的 TVM)。
- **收口阈值:整门课其实是同一个 TVM 在不同尺度上反复出现**——个人储蓄、债券、公司估值、私募 IRR、衍生品定价,全是"今天的钱与未来的钱之间的汇率"。

## 真实评估("毕业"做出什么)
- **L2:** 搭一个分散投资组合并讲清取舍。

- **L4:** 做一个简化 LBO 模型(算 IRR 与 MOIC),并解释三大价值杠杆各贡献多少。
