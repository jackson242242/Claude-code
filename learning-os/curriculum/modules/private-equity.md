## 0. 这个模块教什么(一句话)

**用别人的钱(债)买下一整家公司,把它做得更值钱,几年后卖掉赚差价——而债务像放大镜,把赚和赔都放大。**
然后:**这笔钱是怎么从养老金/大学/富豪(LP)手里,经过基金经理(GP)的手,赚了再按规矩分回去的。**

## 1. 前置(概念依赖图)

这个模块站在前面几个模块的肩上——**没有这些前置,PE 是黑魔法:**

```
TVM/IRR(M0)──┐
现金流/三张表(M4)─┤
WACC/估值倍数(M4)─┼──► LBO(6.1)──► 基金结构与瀑布(6.2)
杠杆/资本结构(M5)─┘
```
> 教学含义:**进这个模块前,门禁要求先掌握"现金流""倍数估值""IRR""杠杆双刃"。** 这就是"结构"。

## 2. 这个模块的阈值概念 & 要打掉的误解

- **阈值③ 杠杆双刃(极致版):** 债不是"免费的钱",它放大**两个方向**。
- **阈值⑤ 价值创造:** PE 赚钱有三个来源,只有一个是"真本事"。
- **要打掉的误解:**
  - ❌ "PE 就是借钱赌一把" → ✅ 回报可拆解、可归因,大部分来自运营改善 + 去杠杆。
  - ❌ "IRR 高就是赚得多" → ✅ IRR 会被时间和财务技巧扭曲,必须和 MOIC 一起看。
  - ❌ "carry 是工资" → ✅ carry 是利润分成,且要先让 LP 拿到门槛收益才轮到 GP。

## 3. 核心知识 A:LBO 的数学(用一个贯穿全模块的例子)

> **贯穿案例「Sleepy Toy Factory」**(沿用并升级 Thomas 课 Mission 9)。同一家公司,从小学讲到研究生。

### 3.1 入场(Entry)
- 企业价值 EV = **$100M**,EBITDA = **$20M** → 入场倍数 = 100/20 = **5.0×**。
- **来源与用途(Sources & Uses):**
  - 用途:买公司 $100M
  - 来源:**自有股权 $40M + 债务 $60M**(忽略费用简化)
  - → 一开始就借了 60%。

### 3.2 持有期(5 年,价值三杠杆)
- **运营改善:** EBITDA 从 $20M → **$30M**(涨 50%,靠提价/降本/增长)。
- **去杠杆(de-lever):** 用每年现金流还债,债务 $60M → **$30M**。
- **倍数:** 退出时假设**仍是 5.0×**(保守,不靠"卖得更贵")。

### 3.3 退出(Exit)
- 退出 EV = 5.0× × $30M = **$150M**
- 减去剩余债务 $30M → **股权价值 = $120M**

### 3.4 回报
- 股权:投入 $40M → 收回 $120M
- **MOIC(倍数)= 120 / 40 = 3.0×**
- **IRR(年化)= 3^(1/5) − 1 ≈ 24.6%**

### 3.5 ⭐ 价值创造桥(Value Bridge)—— 钱到底从哪来的?
股权净赚 = $120M − $40M = **$80M**,拆成三块:

| 来源 | 算法 | 贡献 |
|------|------|------|
| **EBITDA 增长** | ΔEBITDA × 入场倍数 = $10M × 5 | **$50M** |
| **倍数扩张** | ΔMultiple × 退出 EBITDA = 0 × $30M | **$0**(本例没靠这个) |
| **去杠杆** | 还掉的债 = $60M − $30M | **$30M** |
| 合计 | | **$80M** ✅ |

> 教学高潮:**让学生自己拨动这三块,看回报怎么变。** "真本事"是 EBITDA 增长;倍数扩张靠运气/市场;去杠杆靠现金流。

### 3.6 杠杆的双刃(必教的反面)
- **同一家公司,如果全用股权(无债)买:** 投 $100M,EBITDA $20M→$30M,5× 退出 = $150M,无债 → 股权 $150M。
  - MOIC = 1.5×,IRR ≈ **8.4%**。
- **对比:有杠杆 3.0× / 24.6% vs 无杠杆 1.5× / 8.4%** —— 债把回报放大了。
- **但反过来:** 若 EBITDA 跌到 $15M、退出倍数压到 4× → EV = $60M,先还 $60M 债 → **股权归零**。
  无杠杆的话还剩 $60M。**这就是双刃:杠杆越高,翻倍越快,爆仓也越快。**

## 4. 核心知识 B:基金是怎么运转的(6.2)

> Thomas 课只说"给钱的人/管钱的人"。这里讲**真结构**。

### 4.1 谁是谁
- **LP(有限合伙人):** 出钱的——养老金、大学捐赠基金、保险、富豪家族。出钱,但不管事,责任有限。
- **GP(普通合伙人):** 管钱的——私募基金公司。做决策,赚管理费 + carry。
- **承诺 vs 实缴:** LP 先"承诺"$X,GP 在几年投资期内**逐笔 call(催缴)**,不是一次打满。

### 4.2 "2 and 20"
- **管理费 ~2%/年**(按承诺/投入资本),养团队、付日常。
- **Carried interest(carry)~20%**:利润的 20% 归 GP——但**有顺序**(见瀑布)。

### 4.3 ⭐ 分配瀑布(Distribution Waterfall)—— carry 不是张口就拿
$100M 基金、8% 门槛、20% carry、100% catch-up。**钱回来时按这个顺序流:**

1. **① 返还本金:** LP 先拿回他们投入的 $100M(+ 已缴费用)。
2. **② 优先回报(门槛/hurdle):** LP 再拿到 **8% 复利**的优先收益,GP 此时一分 carry 没有。
3. **③ GP 追补(catch-up):** 超过门槛后,GP 先拿 100%,直到 GP 拿到的 = 全部超额利润的 20%。
4. **④ 二八分成:** 之后剩余的利润,**LP 80% / GP 20%**。

> 教学含义:**carry 是"先让 LP 吃饱、GP 才上桌"的利润分成。** 门槛收益保护 LP,catch-up 补偿 GP。

### 4.4 J 曲线
- 基金早年:**净 IRR 为负**——管理费先扣、资本陆续投出,但还没退出、没回款。
- 中后期:退出开始回款,曲线翻正、上扬。形如字母 **J**。
- 教学含义:**判断一支基金不能只看前两年**,早亏是结构性的。

### 4.5 IRR 会被"美化"——为什么要同时看 MOIC
- **认购信贷(subscription line):** GP 先用银行短期贷款投资,推迟向 LP 催缴 → 缩短 LP 资金占用时间 → **IRR 被拉高**,但 **MOIC 不变**。
- 教学含义:**IRR 看"快不快",MOIC 看"翻几倍"。只看 IRR 会被时间游戏骗;两个一起看才诚实。**

## 5. 建造阶梯(同一模块,小学 → 研究生,每级亲手造)

> 建构主义:**先造再懂。** 同一个 Sleepy Toy Factory,作品从玩具版长到专业版。

| 级 | 学段 | 亲手造的作品 | 触及的知识 |
|----|------|-------------|-----------|
| **L0** | 小学低 | 拖拽游戏:用 $4 自己的 + $6 借的买下柠檬水摊,翻新,卖 $15,还 $6,**数自己剩多少** | 杠杆的直觉 |
| **L1** | 小学高/初中 | "Buy-Fix-Sell"小模拟:调"翻新投入",看卖价变化,首次看到"借的要还" | 杠杆双刃(直觉) |
| **L2** | 高中 | 电子表格版:输入入场倍数、债比例、EBITDA 增长,**算出 MOIC** | 倍数、MOIC、Sources&Uses |
| **L3** | 本科 | **亲手建一个 LBO 模型**:债务偿还表 + 退出 + **IRR + MOIC + 价值桥** | 全套 LBO 数学 + 三杠杆归因 |
| **L4** | 研究生/专业 | **建一个基金分配瀑布**(门槛/catch-up/carry)+ 画 J 曲线 + 用认购信贷演示"IRR 被美化" | 基金结构、瀑布、IRR vs MOIC |

**每级毕业 = 交出这个作品(作品即门禁),不是做选择题。**

## 6. 怎么把它做成课程(curriculum → 产品)

> 这是你说的"然后看如何把他做成课程"。桥梁就是 `ARCHITECTURE.md` 的**内容即数据**:
> 每一关 = 一段声明式数据,app 按 `type` 渲染。**写课 = 填数据,不改 app。**

### 6.1 把 L3「建 LBO 模型」这一关拆成 mission steps

| step | type(来自 ARCHITECTURE 积木) | 内容 |
|------|------------------------------|------|
| 1 | `info` + 动画 | 回顾:杠杆是放大镜(Emu 举着放大镜) |
| 2 | `slider-sim` | 拨"债务比例",实时看 MOIC 怎么放大(和爆仓红线) |
| 3 | `build`(新积木:可输入的迷你模型) | 学生填 EBITDA 增长/还债额,系统算 MOIC/IRR |
| 4 | `analyze` | 价值桥三块各贡献多少?拖动条让总和对上 $80M |
| 5 | `explain-back` | 一句话:"这笔 PE 赚的钱主要来自______" |
| 6 | 作品提交 + ⭐ + Emu 长大 | 导出他建的模型 = 毕业作品 |

### 6.2 一关的数据长这样(示意 schema)
```json
{
  "id": "pe-l3-lbo-build",
  "level": "L3",
  "prereq": ["money.m4.dcf", "money.m5.leverage", "money.m0.irr"],
  "bloom": "create",
  "steps": [
    {"type": "info", "title": "杠杆是放大镜", "media": "emu-magnifier.riv"},
    {"type": "slider-sim", "var": "debtPct", "min": 0, "max": 0.8,
     "compute": "moic", "showGuardrail": "wipeout"},
    {"type": "build", "model": "lbo", "inputs": ["ebitdaGrowth","debtPaydown"],
     "outputs": ["moic","irr","valueBridge"]},
    {"type": "analyze", "target": "valueBridge", "mustSumTo": 80},
    {"type": "explain-back", "prompt": "这笔 PE 赚的钱主要来自?"}
  ],
  "artifact": "lbo-model-export",
  "reward": {"xp": 120, "mascotGrowth": true}
}
```
> 关键:`build` 是这个产品**最该重投入的新积木**——一个"可输入参数、实时算、能导出"的迷你建模器。
> 它把"动手造"从口号变成机制,L3/L4 全靠它(LBO 模型、瀑布、DCF 都是它的实例)。
