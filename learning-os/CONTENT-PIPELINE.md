## 2. 降维管线(7 步,每个概念都走一遍)

```
权威源 → ①提取能力目标 → ②建依赖图&分级 → ③降维翻译 → ④内化 → ⑤应用 → ⑥专家复核 → (回炉)
```

1. **提取能力目标(不是抄文本):** 从标准里拉出"学完应能**做**什么"。
   例(投资):"能解释复利、能说明为何越早开始越好、能比较费用对长期收益的侵蚀"。
2. **建依赖图 + 放到 L0–L4 螺旋**(用 `COURSE-DESIGN.md` 的 DAG + Bloom):谁是谁的前置、三年级从哪个原子入。
3. **降维翻译(核心难点):** 同一真理,写成每一级的语言——
   - **具象→表征→抽象(CRA):** 低龄版 = 真类比 + 自己的钱的场景,**不上公式**;高年级再上数字与公式。
   - **简单语言:** 一个原子一个概念、短句、3 分钟讲完;术语**先体验后命名**。
   - **先打误解:** 显式点名常见错误心智模型再纠正。
   - **铁律「简化不歪曲」**(见 §3)。
4. **内化:** 间隔重复(SRS)+ 多变体反复喂(像学语言每个字多种方式)+ **讲回来**(教别人=学会)。
5. **应用(建造优先):** 每级用**学习者自己的真实情境**收尾——记自己的零花钱、规划自己的储蓄目标。应用 = 迁移到真实生活。
6. **专家复核:** 财务专家查"简化后是否仍正确",教育者查"是否适龄"。
7. **回炉:** 复核或试玩发现问题 → 退回对应步骤改。

## 3. 铁律:简化,但不歪曲(simplify, don't lie)

> 把内容做简单很容易,**做简单又不变成错的**才是真功夫。这是质量红线。

- ✅ **省略细节**(先不讲边角)、**用类比**、**用小数字** —— 允许。
- ❌ **把对的讲成错的**(为顺口牺牲正确性)—— 禁止。
- **典型反例(以税务为例;税务属 18+ 内容,此处仅借它说明原则):** 不能说"赚得越多、所有钱都被多扣" → 这是错的。
  必须忠实于**累进/边际**:**只有"多出来那一段"按更高税率**,加薪永远不会让到手变少。
  → 即便给成人初学者,也要把这个真相讲对,而不是图省事讲错。

## 4. worked 例:把「复利/投资增值」从专家级降到三年级(同一真理,三层)

> 用一个**真·三年级可学**的概念演示降维(税务因 18+ 不作低龄样板)。

| 级 | 怎么讲(语言降维) | 守住的真理 |
|----|------------------|-----------|
| **L1 三年级** | "钱放着会自己长大一点点;长出来的那点,明年也会跟着再长——像**滚雪球**,越滚越快。**越早开始,雪球滚的时间越久。**" 用雪球动画。 | 复利=利滚利;时间是关键 |
| **L2 高中** | `FV = PV(1+r)ⁿ`;72 法则;**费用也在复利**——1% 费率 30 年吃掉约 1/4 终值。 | 几何增长;费率侵蚀 |
| **L3 本科+** | 名义 vs 实际(扣通胀)、连续复利、定投年金 FV;为何"在场时间">"择时"。 | 真实回报;长期纪律 |

- **简化不歪曲(反例):** 不能讲成"复利是匀速长大" → 真相是**后期才爆发**(凸性)。低龄版用雪球"越滚越快"把这点讲对。
- **应用作品:** L1 用雪球游戏看"自己的零花钱"10 年;L3 比较"1% vs 0.1% 费率 30 年差多少"。
- **内化:** 这个概念在 L1/L2/L3 三次以不同变体回归(SRS),每次更深——而不是讲一次就过。
